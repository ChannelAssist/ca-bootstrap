§1

Why we're rewriting

A single 90-minute session on 2026-05-25 surfaced three unrelated bugs in normal first-use paths of the PowerShell ca-bootstrap: the documented Windows install one-liner has never worked (#requires + [CmdletBinding()] are incompatible with iex); make on Windows emits literal \033[…] escapes and mojibake'd box characters; ./make.ps1 setup freezes silently. These are not isolated. Six prior commits across the project's history addressed bugs in the same stdio/console/encoding class — including PR #17 which literally dropped the TUI to escape it — yet the class persists. The signal is structural, not surface. PowerShell's interactive-console model is the wrong abstraction for a cross-platform "make a fresh laptop usable" tool.

The Go rewrite ships as a single static binary per platform via GitHub Releases. No pwsh-version dance, no execution-policy fights, no iex/scriptblock puzzles, no child-process stdio inheritance bugs. The PowerShell tree is archived at tag legacy/v1.9.0 and moves to legacy/. Strict process: spec → tests → code. No code lands before its acceptance tests exist.

§4

Decisions locked during brainstorming

10 multiple-choice questions answered in sequence, each one constraining the next.

Repository layout
In-place rewrite
PS tree moves under legacy/; Go tree at repo root. Same URL, history preserved.
Binary name
ca-bootstrap
Continuity — muscle memory carries over from the PS era.
Version line
v2.0.0 (semver continue)
Pre-release tags (-alpha.N, -beta.N) for the parity period.
Manifest format
YAML (unchanged)
Existing manifest/tools.yaml carries over verbatim.
alpha.1 MVP
doctor + version only
Read-only. Smallest possible surface to prove the whole stack end-to-end.
Telemetry
None ever
No phone-home. No opt-in/opt-out UX. Privacy-clean default.
Code signing
Defer to v2.0.0 final
Alphas/betas unsigned; users handle SmartScreen/Gatekeeper click once.
Update mechanism
Built-in self-update
ca-bootstrap self-update lands in beta.1. Single source of truth = GH Releases.
Release matrix
5 platforms
windows/{amd64,arm64} · darwin/{arm64,amd64} · linux/amd64
TUI library
None — plain CLI
Six prior commits prove TUI is the bug magnet we're escaping. No bubbletea, no pterm.
